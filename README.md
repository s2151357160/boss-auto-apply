# BOSS直聘自动投递工具

基于 ADB/HDC + OCR 的 BOSS直聘自动投递效率工具，支持安卓和鸿蒙手机，自动识别岗位信息并批量投递。

## 功能特性

- **双平台支持**：安卓(ADB) + 鸿蒙(HDC)，GUI一键切换，自动记住上次选择
- **关键词过滤**：包含/排除关键词，支持中英文逗号和空格分隔
- **薪资筛选**：设定最低/最高薪资(K)，支持区间重叠匹配
- **面议岗位**：可选投递薪资显示"面议"的岗位
- **自动投递**：检测"立即沟通"自动点击，检测"继续沟通"自动跳过
- **防重复投递**：同一公司只投递一次，持久化到JSON，重启仍有效
- **黑名单公司**：始终跳过黑名单中的公司，GUI添加/查看/清空
- **投递统计面板**：实时显示投递成功/跳过/重复/总计扫描/用时/成功率
- **暂停/继续**：投递过程中随时暂停，当前步骤完成后暂停不丢进度
- **即时停止**：停止信号立即响应，不会等延迟结束
- **投递完成通知**：非阻塞弹窗(3秒自动关) + 自定义音效(mp3/wav/蜂鸣)
- **投递日志双文件**：成功日志和失败日志分开，中文日期时间戳命名
- **日志实时显示**：识别结果区滚动显示 ✓/✗/↻ 汇总行
- **配置持久化**：所有设置自动保存，下次启动自动恢复
- **异常自动恢复**：截图/OCR/点击/滑动/返回失败自动重试，跳过当前岗位不中断
- **自动防风控**：随机偏移点击、1/5概率随机上滑、每10家休息5-10秒、延迟随机波动
- **分辨率自动适配**：优先读取Override size，适配分辨率覆盖的手机
- **ADB状态监控**：软件启动后自动检测，约每5秒刷新连接状态，仅在状态变化时写入日志
- **ADB手动恢复**：提供“启动/检测ADB”按钮，可手动启动内置ADB并等待手机完成连接
- **设备自动重连**：ADB冷启动最长等待15秒；服务卡死或设备offline时自动重启后重新枚举
- **准确连接提示**：区分已连接、未授权、offline、未连接和检测中，不再统一提示“未检测到手机”

## 技术栈

- **GUI**：tkinter（原生 Python GUI）
- **OCR**：RapidOCR（基于 ONNX Runtime）
- **设备驱动**：ADB（安卓） + HDC（鸿蒙），统一抽象层

## 使用方法

### 源码运行

1. 安装 Python 3.12+，确保 ADB 已配置
2. 安装依赖：
   ```bash
   pip install rapidocr_onnxruntime[onnxruntime] opencv-python pillow pyclipper shapely
   ```
3. 手机开启 USB 调试，连接电脑
4. 运行：
   ```bash
   python boss_gui.py
   ```



### 鸿蒙手机

纯血鸿蒙 NEXT 不支持 ADB，需选择"鸿蒙(HDC)"平台，手机开启开发者模式。

### 安卓手机与 ADB

1. 用支持数据传输的 USB 线连接手机和电脑。
2. 在手机中开启“开发者选项”和“USB调试”，并保持手机解锁。
3. 打开软件并选择“安卓 (ADB)”。软件会自动启动内置 ADB，无需用户另行安装或配置 ADB。
4. 查看“启动/检测ADB”按钮右侧的常驻状态。软件约每5秒自动刷新一次：
   - `ADB: 已连接`（绿色）：可以截图识别或开始投递。
   - `ADB: 检测中...`（蓝色）：正在启动服务或读取设备，首次冷启动通常需要约6秒，请稍候。
   - `ADB: 未授权`（橙色）：解锁手机，在手机弹窗中点击“允许USB调试”；建议勾选“始终允许此计算机”。
   - `ADB: offline`（橙色）：连接存在但通信异常，点击“启动/检测ADB”；仍未恢复时重新插拔USB。
   - `ADB: 未连接`（红色）：检查数据线、USB连接模式、手机USB调试和电脑USB驱动。
5. 自动检测异常时，可点击“启动/检测ADB”。按钮会启动或恢复内置 ADB，并弹窗显示具体结果。

#### 在其他电脑上使用

- 单文件 EXE 已内置 ADB、HDC、OCR 模型和 Python 运行环境，可以复制到其他 Windows x64 电脑使用。
- 即使使用同一台手机，换电脑后也必须重新确认一次“允许USB调试”，因为每台电脑使用不同的 ADB 调试密钥。
- 对方电脑仍可能需要安装手机品牌对应的 USB 驱动。系统设备管理器完全看不到手机时，软件和 ADB 都无法自行修复驱动问题。
- 建议把 EXE 放在普通可写目录，不要放入 `Program Files`；配置、名单和日志会写在 EXE 同级目录。

#### ADB连接排障

- 状态长时间停在“检测中”：等待15秒后再点击“启动/检测ADB”，不要连续点击。
- 显示“未授权”：在手机开发者选项中撤销USB调试授权，重新插拔后再次允许。
- 显示“offline”：关闭模拟器、手机助手或其他可能占用ADB的软件，再点击“启动/检测ADB”。
- 显示“未连接”：把USB用途切换为“文件传输/MTP”，更换USB接口或支持数据传输的线，并检查设备管理器驱动。
- 软件只在ADB状态发生变化时写入 `[ADB监控]` 日志，不会每5秒重复刷屏或弹窗。

## 注意事项

- 需要手机通过 USB 连接电脑，开启 USB 调试/开发者模式
- 安卓模式应等待状态显示绿色“ADB: 已连接”后再开始截图或投递
- 手机屏幕分辨率工具自动适配（优先 Override size）
- 投递间隔建议不低于 3 秒，避免触发平台风控
- USB 驱动为系统内核级，无法打包进 exe，需用户手动安装

## 自动停止条件

- 达到投递次数目标
- 连续3次识别到同一岗位（列表到底）
- 检测到弹窗关键词（投递上限/操作频繁/账号异常等）
- 手动点击"停止投递"（即时响应）
